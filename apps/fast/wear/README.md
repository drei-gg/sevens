# Fast Wear companion

## Preset selection

The native Wear Material 3 dialog lists phone built-ins plus saved presets as durations; private names stay on the phone. Version-2 Start carries the preset ID and displayed archive revision. Old phones reject it, changed presets are stale, and retries preserve the original receipt. Version-1 snapshots still offer the labelled 16-hour default. The watch commits its pending queue before transport and confirms queue clearing. Tile/complication content remains timer-only. Native emulator tests cover selection, timeout, model relaunch and matching acknowledgement; paired physical transport is a separate acceptance check.
